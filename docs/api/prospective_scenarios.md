# Prospective scenarios

A premise background scenario and a prospective characterization scenario
describe the same future in two different vocabularies. This module derives
one from the other, axis by axis (`iam`, `ssp`, `rcp`), and holds the rule
deciding which characterization scenario a run uses.

`available_scenarios()` lists both catalogues side by side, including the
scenarios only one of them knows about.

See [TimexLCA](timex_lca.md) for where `characterization_scenario` and
`scenario` are set, and
[Repeated Runs & Scenario Comparison](../content/getting_started/configured_runs.md)
for using this across several runs.
